# Security Policy

## Supported Versions

We release patches and security fixes for the active versions of **PortX**.

| Version | Supported          |
| ------- | ------------------ |
| 5.3.x   | :white_check_mark: |
| 5.2.x   | :white_check_mark: |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :white_check_mark: |
| < 5.0   | :x:                |

## Reporting a Vulnerability

The PortX maintainers take security and ethical network tooling seriously. If you discover a vulnerability or security risk within PortX (such as socket exhaustion, memory leakage, or unauthorized data capture):

1. **Do NOT open a public GitHub issue.**
2. Submit a confidential report via [GitHub Security Advisories](https://github.com/Ali-Rashidi-80/PortX/security/advisories) or contact the project maintainers via [Ali-Rashidi-80/PortX](https://github.com/Ali-Rashidi-80/PortX) with the subject line `[PORTX-SECURITY-REPORT]`.
3. Provide a clear description of the vulnerability, including:
   - Operating system and version (Windows, Linux, macOS, or Android)
   - Step-by-step reproduction instructions or Proof-of-Concept (PoC)
   - Affected component (`shared`, `desktopApp`, or `androidApp`)
   - Potential impact assessment

### Response SLA
- **Initial Response:** Within 48 hours of report submission.
- **Triage & Remediation Plan:** Within 7 business days.
- **Public Disclosure:** Following an agreed-upon responsible disclosure period (standard 30 days) once a patch has been merged and released.

Thank you for helping keep PortX and its open-source users secure!
